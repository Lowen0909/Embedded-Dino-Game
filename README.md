# Retro Handheld
## Development environment
* Board:STM32 F407VG-DISC1  
* IDE:STM32CubeIDE v1.11.0  
* LCD module:Waveshare 1.14 inch lcd module (ST7789)   
* Onboard motion Sensor:LIS3DSH

## Drivers and Libs
LCD driver:[Waveshare](https://www.waveshare.net/wiki/1.14inch_LCD_Module)
Motion Sensor lib:[MYaqoobEmbedded/STM32-Tutorials](https://github.com/MYaqoobEmbedded/STM32-Tutorials/tree/master/Tutorial%2027%20-%20Motion%203-Axis%20Accelerometer%20LIS3DSH)
